# Registro de cambios de EDUMARKET RD

## Versión inicial de documentación: 0.1.0

### Cambio 1. Organización de los requisitos
Se organizaron los requisitos funcionales relacionados con la búsqueda de recursos, el registro de usuarios, el inicio de sesión, las categorías y las actividades educativas infantiles.

### Cambio 2. Modelado UML
Se identificaron las clases principales del sistema: Usuario, RecursoEducativo, Categoría y ActividadInfantil, como base para representar su estructura.

### Cambio 3. Propuesta de arquitectura
Se documentó la arquitectura por capas, separando frontend, backend, acceso a datos y base de datos. También se estableció la comunicación prevista mediante servicios o API.

### Cambio 4. Organización del seguimiento
Se utilizó GitHub Projects para organizar las tareas en Backlog, Por hacer, En progreso, En revisión y Finalizado.

### Cambio 5. Actualización de la documentación técnica
Se preparó la documentación del sistema mediante el README.md, incluyendo su objetivo, funcionalidades, arquitectura, herramientas utilizadas y próximos pasos.

## Nota
Este registro resume los avances documentados durante el proyecto. No significa que todas las funcionalidades estén implementadas o probadas. Los cambios de código deberán registrarse conforme se realicen mediante Git.
